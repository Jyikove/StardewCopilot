# 人格与功能验收

当前版本 0.19.0。以下自动测试验证请求、证据和上下文传递；真实模型是否自然、是否选对当天重点，必须另做游戏内验收。

## 发现与修改

旧规则只要求“有价值才建议”，没有具体区分当前问题、重要遗漏与普通额外知识；普通聊天没有日常规划的重点筛选规则，搜索又固定要求 3–5 项行动和 3–5 段收尾，容易促使模型扩展成工作汇报。疲惫、想休息和单纯准备出门等陈述也可能被强制送去检索。

现在的共享语气继续用“老大”作为固定称呼，但自然省略、不固定句首、单条不重复、相邻回复避免连用。提醒采用亲切日常口语，避免命令口吻，不增加无关情绪、建议或物品拟人。

普通对话的互动策略区分事实、追问、分享、吐槽和休息。分享不强加下一步攻略；吐槽可补充可靠实用的挽回信息，机制仍需检索；想休息时不改派其他活动。准备行动时接住意图，只轻提醒重要易遗漏事项，已经拒绝的不反复催促，可选优化不说成紧急任务。

日常规划规则由普通聊天、搜索和截图共享：核实后默认突出 2–3 件重点，考虑临近截止、易错过窗口、当天合适的未完事项和明确目标，保留时间、物品、地点等关键限制；完整请求或确有多项限时事项时再展开。普通额外知识通常不加，不复述全量状态、喜好或建筑条件。帮助保持功能解释，不注入每日规划。

状态概要已经紧凑，细节由现有工具实时查询，本次不删减事实或新增固定任务排序器。明确闲聊、分享、疲惫和单纯行动意图只取消强制预检；游戏与 Wiki 工具仍可主动调用，含事实问题、规划、特殊指令等保持原有核实路径。历史摘要已有长期目标、未完成计划与交流偏好规则，本次保留，不增加情绪数据库、API 调用或持久人格状态。

安装后正常保存并重启 SMAPI，确认加载 0.19.0。使用测试存档，先建立一个真实长期目标并表达“别反复催我送礼”。准备当前未浇水的作物、已存在且临近截止的任务；没有这些状态时，助手应查询后如实说明，不能为符合下面的场景编造。
